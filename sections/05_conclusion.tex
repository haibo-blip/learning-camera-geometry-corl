This paper studies camera geometry as a learned component of visuomotor control rather than as fixed calibration metadata. The action-only variant tests whether partial pose supervision and action loss can jointly train a useful camera-aware policy. The NVS variant adds a view-synthesis objective that regularizes latent scene tokens through held-out view reconstruction. Together, these variants suggest a path toward camera-aware robot policies that learn geometry inside the control objective and avoid a separate explicit 3D reconstruction pipeline.
